This Portfolio Website

A responsive, multi-page personal site built from scratch, and the one you're using right now.

Overview

This site is built with plain HTML, CSS, and JavaScript, no framework, no build step. The goal was a fast, clean, content-first design that gives two different disciplines (data analytics and web development) their own space under one consistent visual system.

What's under the hood

  • Structure: Multi-page static site (Home, Portfolio, Resume, individual project case studies) linked through a shared nav and footer.
  • Styling: A single hand-written stylesheet using CSS custom properties for color, spacing, and radius, so the whole look can be re-themed from one place.
  • Typography: Space Grotesk for headings, Inter for body text, and JetBrains Mono for data callouts and labels, a pairing chosen to fit an analytics-and-code identity.
  • Interactivity: Vanilla JavaScript for the mobile nav toggle, expandable bio text, and the contact form's submit state, no framework needed for this scale.
  • Responsive design: A fluid grid layout that reflows from a multi-column desktop view down to a single-column mobile view, with a collapsible nav menu below 800px.

Design decisions

Rather than using a template, every section, the hero, the interest cards, the project grid, was custom-built to keep the layout consistent and lightweight. Icons are inline SVG rather than an icon font or emoji, which keeps them crisp at any size and themeable with CSS.
